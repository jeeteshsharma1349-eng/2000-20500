GREENLINE ATELIER — 24% Daily Stop-Loss Patch

This package contains a focused patch for the HTML you pasted in chat.
It preserves your existing dashboard by showing exactly what to add/change,
rather than replacing your full dashboard with a different template.

HOW TO APPLY
1. Open your existing GREENLINE HTML file in a code editor.
2. Apply the changes in PATCH.txt in the listed order.
3. Save the file and open it in Chrome.
4. In Challenge Settings, set Stop Loss (%) to 24 and click Apply settings.

BEHAVIOUR
- Stop-loss threshold is based on that day's opening balance.
- Example: opening ₹1,000 and 24% stop loss => floor ₹760.
- Once settled trade results bring the balance to or below that floor,
  no more trades can be added or pending trades resolved for that day.
- The next challenge day gets a fresh threshold based on its opening balance.

IMPORTANT
This is a browser-side tracking safeguard, not a guarantee of trading outcomes
or a connection to a trading platform. It cannot stop trades placed externally.
Back up your data before editing the HTML.
